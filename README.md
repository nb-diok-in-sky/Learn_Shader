# 渲染半透明物体
渲染半透明物体的时候shader渲染队列需要调整至TranseParent 俗称记得切换一下渲染队列把它变成TransParent
同时部分特殊材质，比如说能量护盾、玻璃、晶体（钻石这种） 需要渲染两次物体
需要使用两个shader来完成渲染
一个开启正面剔除，调整渲染队列较后者靠前
另一个开启背面剔除，调整渲染队列较前者靠后 就算只后1位都行
同时，半透明材料标配开启ZWrite Off.不然会遮挡物体后面原本可见的物体
还需要设置混合模式Blend Mode 比如说调整到 Blend SrcAlpha OneMinusSrcAlpha之类的 这个用来决定当前片元如何与已有颜色进行混合（和已经渲染的非透明物体颜色怎么处理）
部分渲染对象需要关闭阴影，比如说在地上放了个能量罩，明明是能量组成的，却有投影，多奇怪




Time函数
运用Time函数可以获取一个随时间增长的float值
而Unity里面的_Time有4个分量 x分量会获得t/20,而y分量会获得一个普通的t，z分量会获得t* 2，而w分量会获得t*3
配合Fract（截取小数部分)方法就可以获得一个个反向的N字函数
这会使得数值在每个周期内从0线性增长到1，然后瞬间归0，如此循环往复，获得闪烁的效果，可以用来驱动循环动画

smoothstep
平滑过渡，这个方法给你设置一个Min值和Max值
当你小于Min值的时候，输出值为0
当你大于Max值得时候，输出值为1
当你处于Min和Max之间的时候会输出一个不同于lerp的匀速过渡，在值靠近Min和Max的时候会自动的减速，让过渡更加平滑一些，
数学上的描述是smoothstep的内部实现是三次Hermite曲线：t = clamp((x-min)/(max-min), 0, 1); return t*t*(3-2*t)。这条曲线的特点是在两端（t=0和t=1处）导数为0，即过渡起点和终点都是"切入/切出"的，不会有突兀的折角


lerp插值
这个用的也蛮多的，在GLSL里面他叫mix
接口给了三个通道分别接受起始值A，目标值B，以及混合权重T(Alpha）
功能是用来融合，
传入了两个值，A的大小在图中占的权重为1-Alpha
B的权重大小为Alpha
当Alpha为0的时候，A值就占了一整个图像，Alpha为1时，B值占了一整块图像
这个Alpha的可操作空间就比较大了，他可以用来调整B值的范围，比如说用来调整燃烧的是时候，你物体本体和燃烧火星的占比
即Alpha =0时，输出值为A  Alpha=1时，输出值为B Alpha位于0到1之间的时候，Alpha值越大，B值所占权重越大，反映到图像上是B图像的颜色会u多一些



dot 点乘
几何意义：两个向量夹角的余弦值
可以拿来速断方向关系，结果大于0意味着两向量同向，等于0说明垂直，小于0说明反向（实质是cos函数的数值变化运用）
小于0的在光照计算里面很实用啊，说命这个面是背光的，可以拿saturate裁剪掉
以上几何意义的成立的前提条件是点乘向量均已归一化，没有归一化需要除以两者的模长乃能拿去用 如果传入的是法线也要归一化
反正归就完了



UV采样的本质
UV采样就是在一张0-1的范围贴图范围上查找数组
比如说
屏幕上的点 A → 去 (0.3, 0.5) 取色
现在把这个采样点在U方向加上了偏移值0.1
原来：A去 (0.3, 0.5) 取色
现在：A去 (0.3 + 0.1, 0.5) = (0.4, 0.5) 取色
所以说UV偏移的实质是采样点发生的变化 UV本身是静止的 只是采样点整体偏移，所以
显得图像好像偏移了一样 实际上是图像的值没变，你去找值的位置变化了
超出0-1范围的值由你的贴图设置决定 通常都是设置重复，要不然是就是镜像
当设置为重复的时候
通常超出UV范围部分的地方会自动截断，只取小数部分(等于执行了frac的方法，对1取模)，结合前面的偏移来看，超出右边边界的内容会重新从左边边界出现
即所有的左边来到了右边，最右边的回到了最左边
UV超出[0,1]时的处理模式除了Repeat（重复）外还有：Clamp（边缘像素拉伸，超出部分取边界色）、Mirror（镜像重复，奇数次翻转）、MirrorOnce（只镜像一次，之后Clamp）
实际做流动效果时用Repeat，做局部特写贴图时常用Clamp，Mirror用于做无缝对称纹理。

# 后处理效果
这个是unity里面的PostProcessing插件
可以很快提升画面质感与效果
具体使用方法是新建一个Layer名为PostProcessing，位列最后。选中Main Camera，修改摄像机的Layer名为PostProcessing，新建PostProcess Layer以下简称Post L和 PostProcess Volume以下简称Post V
Post L里 Trigger选项点击new，或者选中你的摄像机对象  Post V里Profile选项使用刚刚新建的相机
在Post V里面选择Add effect可以进行选项 一般选择的有Bloom 选项 主要勾选 Intensity 和Threshold选项

要不然值都停留在1以内，再亮也不会溢出形成光晕

这套流程是用在unity旧版管线的流程 新版URP/HDRP已经内置Volume系统 是通过Global Volume组件添加的Override的 



# 边缘光：菲涅尔效果
<img width="1428" height="678" alt="Edge_Light" src="https://github.com/user-attachments/assets/2cb74df5-9e3e-458a-88ba-c97a1ab4e0b2" />
原理：以视角位于正方形上方，以垂直视角观察一个平面为例：
将视角位置视为一个点，通过获取当前顶点法线与视线方向点乘，来得到顶点与视角的余弦值，在cos0°的时候，余弦值为1，此时片段为白色
由于平面上不同的点法线与视线方向夹角不同，且夹角通通大于0°，所以会余弦值越来越小，此时形成中心点最大其他点的余弦值依次变小，即反映在灰度图上中间白两边灰的情况，此时使用1减刚刚的余弦值 会获得中间小两边大的情况，即边缘光。

现实中边缘光通常来自于背后光源，单纯1-N dot V所获得的边缘光是在360°范围内包围物体，怎么看都有光，所以如果需要设置在背面才显示边缘光
得使用Light Dir来替代View Dir 通俗就是说用灯光的视角来替代主视角，模型上生成边缘光，此时正面也有，背面也有，我们要保留正面，剔除背面，所以可以对刚刚的dot(N,LightDir)取负，此时原本处于背光面（N与光源方向夹角大于90°，点乘为负）的区域变为正值，正光面变为负值，再用saturate截断负值，即可保留背光面的边缘光，剔除正光面的边缘光，还原现实中背景光源打出轮廓光的效果。"
（卡渲无需在意）

## 注意点 ##
World Normal 和View Direction需要在同一个坐标空间内才能进行点乘，比如说都在World Space 或者View Space里面
如果是比较基于物理，想要实现PBR效果的边缘光可以在一减后增加一个常数代表材质固有反射率，通常可以百度查到



# 流光效果
 <img width="2529" height="717" alt="FlowLight" src="https://github.com/user-attachments/assets/cfcb1f83-6952-4558-a435-2048c1929b79" />
流光效果的核心是控制物体表面顶点对noise贴图(条纹/线框贴图（科技感电路板）、扭曲液体贴图（能量液体感）、点阵扫描贴图（雷达感））进行采样
通常使用World Position 减去 物体中心点(世界空间下) 此时模型顶点得到的方向是从模型中心指向顶点的偏移向量，然后整合各个顶点的向量，将他们的XY分量头因到水平面后

之后拿去panner方法里面让他的UV进行乘以Time.y和Speed
此时调整Speed值 UV就会开始动起来 以这个UV拿去采样噪声贴图就行，这个噪声贴图就是流光的具体内容，也可以把他换成其他的贴图，比如说有科技感一点的贴图

# UV扰动
<img width="2112" height="1076" alt="UV_disturbute" src="https://github.com/user-attachments/assets/4ee22eff-093f-4074-a1cb-0cdc5e63a607" />
UV扰动——通常使用noise贴图对现有图片uv进行扰动，常用于不规则特效，用处较多，一层低频大波动和一层高频小细节的noise贴图乘以不同的intensity是比较好的进阶选择
是用noise贴图与想要进行扰动的贴图相加，得出结果
具体做法是先声明noise贴图，然后接入他的Texture Coords 采取他的xy分量,或者单独取x，y分量对原UV进行相加
描述还满简洁，用的老多了
原理是：
noise贴图是本质上是一张二维的图，在每个通道上，图上每一个点存储一个0-1的值，有空间连续性的随机，展现的是0-1之间不同的黑白灰度值，具有不规则感。
可以用不同的通道分别对U通道V通道进行扰动，回更加丰富自然
正常uv与noise贴图相加 反映到数据层面是0到1的xy坐标系的uv值进行了不规则的0-1之间的变化，会使得uv的黄绿红图颜色不再那么规律
用一张不规律的贴图，去"污染"（扰动偏移）原本规则的 UV 坐标，使得采样位置发生偏移，从而让原贴图"长歪"。偏移量的大小由 Intensity 控制，方向由 Noise 的正负值控制。
而通常为了使得Noise贴图产生的变化更丰富，通常将其范围从0-1限制到-1到1 或者 -0.5——0.5 反正一正一负数 当然 0——1 也不是不行 就是他只会朝着一个方向偏移 还是得跟着项目来
如果要让noise动起来，那还得加上time函数，用来调整speed 或者直接用panner方法轮椅解决，


除此之外还有乘法
uv + noise[-0.5,0.5]标准扰动，四面撕扯//基于repeat重复模式，这是因此时noise的均值是0，你在noise上面的采样一会是黑一会儿是白，同时他的范围还正好是-0.5——0.5，这是一个特殊值，特殊在他的均值就是0
这意味着被往左推的像素数量 ≈ 被往右推的像素数量
被往上推的 ≈ 被往下推的
整体重心不移动，图像是在原地"四面撕扯"

uv + saturate(noise)单向偏移，图像整体飘移
uv * noise非均匀收缩，塌陷感
uv + noise * noise大部分平静，局部突变

# 高光点获取（星星闪烁效果）

# 鼠标点击场景交互

然后可以相对应的，如果触发的事件或者修改的值会需要根据射线具体点来进行某种变化的话，可以使用粒子系统 通过发射不断前进，不断改变位置的粒子，来使得对应应该修改的参数动态变化

被丢弃的部分需要实现模型从上到下进行丢弃 所以直接采取UV的V分量，让他减去一个可供调整的变量然后用一减即可，此时使用剔除函数，通过变量来进行物体的剔除来完成生长部分
剩下的就是控制模型顶点进行偏移 示例接口在Local Vertex Offset  在手搓代码里面是调整v.vertex.xyz的值
这个模型使用的是不封顶的圆柱体
不管怎么样 总体思路是 1 获取某段你想要改变的顶点的位置，这个位置是需要求出这个位置具体在模型整体的哪一部分，并非单纯截取了某个固定的空间坐标    2对顶点进行你想要的偏移 
核心思路是获取你想要的那一部分 这个案例的目标是获取物体顶部到物体中部的那一段数值

这个弯曲的模型可能会使得无法明确原理，咱们把它当成寻常的圆柱体，将圆柱体进行顶点变换后弯曲才成了现在这个样，所以解释会基于普通圆柱体进行
我们通过使用纹理坐标的方式来来获取对应的位置的在模型表面的坐标
所以先声明一个普通的UV坐标，将它减去某个常数，这就使得我们获得了一个从下到上，从黑到白的值，把这个值拿去乘以顶点法线就足以应付顶点偏移了的结果了
但是效果不是很好，它会呈现一个均匀的锥形，所以我们引入了smoothstep，通过参数来控制锥体具体到某个位置的粗细程度，同时为了更加精确的控制我们的目标
考虑使用两个smoothstep 以及一个Max来取其最大值
这里要搞清楚一个前提，我们黑色的地方是想要他缩小的地方，而白色的地方是让他放大or不变的地方，以此为前提，进行阐述：
在Max下，一个是减少过常数的V分量，一个是常态0-1之间取值的V分量 
他们两个的V分量进行插值，当我调整smoothstep的min和max值，会使得V值变大变小的时候，
图上还蛮明显：从上到下是从黑到白，我们的max会对比从上到下拿一个值更大，然后把他选为最终输出的值
而从上到下正好对应着圆柱体从上到下的World Pos.y 就是通过修改这个min 和max值来控制黑白值
之后拿着这个黑白值去乘以顶点法线，就可以实现局部法线外扩or内缩
后面新add了一个顶点法线，那个是更方便的控制法线外扩or内缩，因为它；关联的变量很少，不加也行，调整的比较麻烦就是。
做这个的时候要保持顶点法线跟着这个同步进行变换，要不然在光照计算里面会出错，模型会基于错误的法线进行判断
更进阶一点的内容可以使用sin(_Time.y * freq + WorldPos.x * spread) * amplitude
使用sin函数缉在某个方向进行驱动顶点位置偏移，可以乘以UV的V分量让摆动幅度更大，目的是为了模拟草在根部固定，尖端随风摆动的效果(这一部分内容有待验证)
