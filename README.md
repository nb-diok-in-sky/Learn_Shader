dot 点乘
几何意义：两个向量夹角的余弦值

UV采样的本质
UV采样就是在一张0-1的范围贴图范围上查找数组
比如说
屏幕上的点 A → 去 (0.3, 0.5) 取色
现在把这个采样点加上了偏移值0.1
原来：A去 (0.3, 0.5) 取色
现在：A去 (0.3 + 0.1, 0.5) = (0.4, 0.5) 取色
所以说UV偏移的实质是采样点发生的变化 UV本身是静止的 只是采样点整体偏移，所以
显得图像好像偏移了一样 实际上是图像的值没变，你去找值的位置变化了
超出0-1范围的值由你的贴图设置决定 通常都是设置重复，要不然是就是镜像
当设置为重复的时候
通常超出UV范围部分的地方会截断只取小数部分，结合前面的偏移来看，所有的左边来到了右边，最右边的回到了最左边

# 边缘光：菲涅尔效果
<img width="1428" height="678" alt="Edge_Light" src="https://github.com/user-attachments/assets/2cb74df5-9e3e-458a-88ba-c97a1ab4e0b2" />
原理：以视角位于正方形上方，以垂直视角观察一个平面为例：
将视角位置视为一个点，通过获取当前顶点法线与视线方向点乘，来得到顶点与视角的余弦值，在cos0°的时候，余弦值为1，此时片段为白色
由于平面上不同的点法线与视线方向夹角不同，且夹角通通大于0°，所以会余弦值越来越小，此时形成中心点最大其他点的余弦值依次变小，即反映在灰度图上中间白两边灰的情况，此时使用1减刚刚的余弦值 会获得中间小两边大的情况，即边缘光。

现实中边缘光通常来自于背后光源，单纯1-N dot V所获得的边缘光是在360°范围内包围物体，怎么看都有光，所以如果需要设置在背面才显示边缘光
得使用Light Dir来替代View Dir 通俗就是说用灯光的视角来替代主视角，模型上生成边缘光，此时正面也有，背面也有，我们要保留正面，剔除背面，所以可以对余弦值取负，此时
原本背面负数的cos值会变成正数，正面会变成负数，再使用saturate方法剔除掉负数值 即可生成现实常见边缘光
（卡渲无需在意）

## 注意点 ##
World Normal 和View Direction需要在同一个坐标空间内才能进行点乘，比如说都在World Space 或者View Space里面
如果是比较基于物理，想要实现PBR效果的边缘光可以在一减后增加一个常数代表材质固有反射率，通常可以百度查到

# UV扰动
<img width="2112" height="1076" alt="UV_disturbute" src="https://github.com/user-attachments/assets/4ee22eff-093f-4074-a1cb-0cdc5e63a607" />
UV扰动——通常使用noise贴图对现有图片uv进行扰动，常用于不规则特效，用处较多。
是用noise贴图与想要进行扰动的贴图相加，得出结果
具体做法是先声明noise贴图，然后接入他的Texture Coords 采取他的xy分量,或者单独取x，y分量对原UV进行相加
描述还满简洁，用的老多了
原理是：
noise贴图是本质上是一张二维的图，图上每一个点存储一个0-1的值，有空间连续性的随机，展现的是0-1之间不同的黑白灰度值，具有不规则感。
正常uv与noise贴图相加 反映到数据层面是0到1的xy坐标系的uv值进行了不规则的0-1之间的变化，会使得uv的黄绿红图颜色不再那么规律
用一张不规律的贴图，去"污染"原本规则的 UV 坐标，使得采样位置发生偏移，从而让原贴图"长歪"。偏移量的大小由 Intensity 控制，方向由 Noise 的正负值控制。
而通常为了使得Noise贴图产生的变化更丰富，通常将其范围从0-1限制到-1到1 或者 -0.5——0.5 反正一正一负数 当然 0——1 也不是不行 就是他只会朝着一个方向偏移 还是得跟着项目来
如果要让noise动起来，那还得加上time函数，用来调整speed 或者直接用panner方法轮椅解决，


除此之外还有乘法
uv + noise[-0.5,0.5]标准扰动，四面撕扯//基于repeat重复模式，这是因此时noise的均值是0，你在noise上面的采样一会是黑一会儿是白，同时他的范围还正好是-0.5——0.5，这是一个特殊值，特殊在他的均值就是0
这意味着被往左推的像素数量 ≈ 被往右推的像素数量
被往上推的 ≈ 被往下推的
整体重心不移动，图像是在原地"四面撕扯"

uv + saturate(noise)单向偏移，图像整体飘移
uv * noise非均匀收缩，塌陷感
uv + noise * noise大部分平静，局部突变


# 获取物体边缘方法（将物体边缘值变成0）
<img width="2112" height="1076" alt="Get_Edge" src="https://github.com/user-attachments/assets/7f027b14-976b-406f-bc19-b171c8eaf95d" />
以四边形物体举例
随便拿一个UV图过来 他从左到右是从0到1，从下到上是从0到1，这都是数值渐变，可以通过获取U or V 分量来得到
这样可以获取物体一边的边缘，或者说规则uv的边缘，那另一头咋获取呢以U分量
举例子
既然可以获取一边的数值，那我们把另外一边变成相同的数值就行了
我们可以将反映到物体上的数值从0到以改成-1到1，然后取绝对值，这样两边的值就相同了
比如说拿U分量乘以-2 然后加一 这样 然后取绝对值 就得到了一个两边的值相同的长条
此时边缘的值还是1 问题不大 拿1减这个值就好了
V分量也是一样的
UV结合的话就是拿调整好的UV值相乘就行了 搞定

# 高光点获取（星星闪烁效果）
<img width="1436" height="642" alt="Get_Hightlight" src="https://github.com/user-attachments/assets/6a2ccc23-e173-48c2-86b7-c619ed1c356e" />
这个就是把你想要的图片做一个power处理 
原理是：在灰度值上越接近0越黑 越接近1越白，通过使用幂函数的方法 使得大于0的地方越来越亮 小于0的地方越来越暗 这样就把高光点找到了
你需要确保你想要的点在灰度上是大于0，要不然还需要后面进一步进行强度调整
